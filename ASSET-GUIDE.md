# Asset guide

Put future files here so the project stays organized.

## Images
public/assets/images/products/
public/assets/images/banners/
public/assets/images/brand/

## Music
public/music/
Suggested naming:
- ambient.mp3
- home-theme.mp3
- login-theme.mp3
- notification.mp3

Keep audio optional and muted by default where browser autoplay policies require user interaction.

## Video
public/video/
- hero.mp4
- promo.mp4
- login-reference.mp4

## Fonts
public/fonts/

## Icons
public/icons/

After adding assets, reference them with `/assets/...`, `/music/...`, `/video/...`, etc.
