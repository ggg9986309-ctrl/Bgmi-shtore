# KIRUU STORE

A scalable React + Vite e-commerce starter prepared for Render.

## Render
Environment: Node
Build Command: `npm install && npm run build`
Start Command: `npm start`

## Add your future assets
- `public/assets/images/products/` product images
- `public/assets/images/banners/` banners
- `public/music/` background music / sound assets
- `public/video/` promotional videos
- `public/fonts/` local fonts
- `public/icons/` custom icons

## Supabase
Copy `.env.example` to `.env` and add only the public Supabase URL and anon key.

Never put a Supabase service-role key in frontend code.

## Project structure
The folders are intentionally separated so new products, music, videos, pages, services, hooks and admin features can be added without reorganizing the whole project.
